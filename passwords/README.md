# Библиотека словарей

Положите сюда файлы словарей (`.txt`, `.lst`, `.dic` и др.) — они появятся в меню SATANA:

**Меню офлайн расшифровки → Personal → пункт 6** — атака по словарю из библиотеки.

Примеры: `rockyou.txt`, `10Mpass.txt`, `wifi_common_passwords.txt`.

Крупные словари не хранятся в Git (лимит GitHub). Скачайте их локально в эту папку.
