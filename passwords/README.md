# Библиотека словарей

Положите сюда файлы словарей — они **сразу** появятся в меню SATANA (пункт **6** в офлайн-расшифровке):

- `*.txt`, `*.lst`, `*.dic`, `*.wordlist`, `*.pass`, `*.pwd`
- любой файл **без расширения** (если размер ≥ 64 байт)

**Не показываются:** `README.md`, другие `.md`, архивы, `.cap` и служебные файлы.

Словари из **корня проекта** (например `wifi_common_passwords.txt`) автоматически копируются сюда при открытии библиотеки, если их ещё нет в `passwords/`.

Папка по умолчанию: `passwords/` рядом с `satana.sh`  
Своя папка: `export SATANA_PASSWORDS_DIR="/путь/к/passwords"`
